# Contributing

## Branch strategy

- main
- develop
- feature/*
- bugfix/*
- hotfix/*
- release/*

---

## Commit Convention

We follow Conventional Commits.

Example:

feat(auth): add login

fix(api): pagination

docs(confluence): update architecture

---

## Pull Requests

Every PR must:

- Pass CI
- Be linked to Jira
- Be reviewed
- Update documentation if needed

---

Frontend

- ESLint

Backend
